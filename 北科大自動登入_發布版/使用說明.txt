# 北科大自動登入系統 (可攜式發布版)

這是一個極輕量、安全的北科大自動登入外掛。

## 系統需求
- Windows 系統
- 必須安裝 Python 3.10 或以上版本 (安裝時請務必勾選 `Add python to PATH`)
- Google Chrome 瀏覽器

## 安裝方式 (超級簡單)
1. 將這個資料夾放在你喜歡的地方 (例如 D 槽或文件，請不要放桌面以免不小心刪掉)。
2. 點兩下執行「一鍵安裝.bat」。
3. 按照黑畫面上的中文提示，輸入你的學號密碼。
4. 打開 Chrome 瀏覽器，網址列輸入 `chrome://extensions/`
5. 打開右上角「開發人員模式」，點擊「載入未封裝項目」，選擇裡面的 `chrome_ext` 資料夾。

大功告成！以後只要開機，進北科大入口網站就會全自動登入囉！

## 常見問題
- **黑視窗是什麼？** 
  程式在背景算驗證碼的小型伺服器，非常省資源 (大約只佔 50MB 記憶體)，請讓它縮小在底下就好，不用理它。

- **密碼存在哪裡？** 
  密碼只存在這個資料夾裡面的 `.env` 檔案中，完全不會上傳到網路，請絕對放心。

- **未來如果在校務系統改了密碼怎麼辦？** 
  只要點兩下執行資料夾內的「修改帳號密碼.bat」，重新輸入一次新密碼就可以了。

- **要怎麼解除安裝？**
  1. 點兩下執行「一鍵解除安裝.bat」，它會自動幫你清除開機啟動設定、虛擬環境與帳號密碼。
  2. 在 Chrome 擴充功能頁面將「北科大自動登入輔助」點擊移除。
  3. 直接將整個資料夾丟進資源回收桶即可乾淨移除。
